# ProjetoGit

entre no windows powerpoint e digite cada um desses a seguir:
mkdir atividade-git && cd atividade-git
touch readme.txt
git config --global user.name "Lucas"
git config --global user.email "lucas.almeida.silva18@gmail.com"
git init
echo "Atividade de Git realizada por Lucas" > readme.txt
git add readme.txt
git commit -m "Primeiro commit"

para adicionar arquivo:

git add .
git commit -m "Primeiro commit: criando e modificando arquivo"
